EXERCÍCIO 1 — LISTAS
==================================================

>>> things = ['chocolate', 'viagem', 'música', 'praia', 'filmes']

>>> print(things)
['chocolate', 'viagem', 'música', 'praia', 'filmes']

>>> print(things[2])
música

>>> things[2] = 'livros'

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes']

>>> things.append('sorvete')

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.insert(0, 'café')

>>> print(things)
['café', 'chocolate', 'viagem', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.insert(3, 'gatos')

>>> print(things)
['café', 'chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.pop()
'sorvete'

>>> print(things)
['café', 'chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes']

>>> things.pop(0)
'café'

>>> print(things)
['chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes']

>>> things.pop(2)
'gatos'

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes']

>>> print(', '.join(things))
chocolate, viagem, livros, praia, filmes


OBSERVAÇÕES:

Em Python, os índices das listas começam pelo zero. Então, quando usamos things[2], 
estamos pegando o terceiro elemento da lista.

O append() serve para adicionar um elemento no final da lista, enquanto o insert() 
permite colocar um elemento em uma posição específica.

Já o pop() remove um elemento da lista e mostra qual foi removido. Se não colocarmos uma posição, 
ele remove o último elemento.

O join() é usado para juntar os elementos de uma lista de textos em uma única frase, usando um separador.

Com esse exercício, deu para entender que as listas são mutáveis, ou seja, podemos alterar, 
adicionar e remover elementos depois que a lista já foi criada.

EXERCÍCIO 2 — STRINGS, LISTAS E ORDENAÇÃO
==================================================

Código:

taxa = "sapiens, erectus, neanderthalensis"

print(taxa)
print(taxa[1])
print(type(taxa))

species = taxa.split(", ")

print(species)
print(species[1])
print(type(species))

print(sorted(species))
print(sorted(species, key=len))

Comando utilizado:

python3 Python04_2.1.py


RESULTADO:

sapiens, erectus, neanderthalensis
a
<class 'str'>
['sapiens', 'erectus', 'neanderthalensis']
erectus
<class 'list'>
['erectus', 'neanderthalensis', 'sapiens']
['sapiens', 'erectus', 'neanderthalensis']


OBSERVAÇÕES:

A variável taxa é uma string, como demonstrado pelo resultado
<class 'str'>. A indexação começa em zero, portanto taxa[1]
retorna o segundo caractere da string.

O método split(", ") divide a string usando vírgula e espaço
como separador, criando uma lista chamada species.

A variável species é uma lista, como demonstrado pelo resultado
<class 'list'>.

A função sorted() retorna os elementos em ordem alfabética.
Quando usamos key=len, a ordenação passa a considerar o tamanho
de cada elemento como critério.

Também foi observado que sorted() retorna uma lista ordenada
sem modificar a lista original.

EXERCÍCIO 3 — Cópia de listas
================================================== 

Método 1:

my_list = ['a', 'bb', 'ccc']
list_copy = my_list
print(my_list)
list_copy.append('dddd')
print(my_list)

Resultado:

['a', 'bb', 'ccc']
['a', 'bb', 'ccc', 'dddd']

Método 2:

my_list2 = ['a', 'bb', 'ccc']
list_copy2 = my_list2.copy()
print(my_list2)
list_copy2.append('dddd')
print(my_list2)

Resultado:

['a', 'bb', 'ccc']
['a', 'bb', 'ccc']

Conclusão:
A diferença é que, no primeiro caso, "list_copy" e "my_list" apontam para a mesma lista. Então, se eu mudar "list_copy", a mudança também aparece em "my_list".

No segundo caso, ".copy()" cria uma nova lista, separada da original. Por isso, se eu alterar "list_copy2", "my_list2" continua igual.

EXERCÍCIO 7 — Soma dos números pares e ímpares

==================================================

Código:

numbers = [101, 2, 15, 22, 95, 33, 2, 27, 72, 15, 52]

numbers = sorted(numbers)

soma_pares = 0
soma_impares = 0

for n in numbers:
    print(n)

    if n % 2 == 0:
        soma_pares += n
    else:
        soma_impares += n

print("Soma dos números pares:", soma_pares)
print("Soma dos números ímpares:", soma_impares)


Comando utilizado:

python3 Python04_7.1.py

Resultado:

2
2
15
15
22
27
33
52
72
95
101
Soma dos números pares: 150
Soma dos números ímpares: 286

Conclusão:

A função "sorted()" organiza os números da lista em ordem crescente. Depois, o comando "for" percorre cada número e verifica se ele é par ou ímpar. Os valores pares são adicionados em "soma_pares" e os ímpares em "soma_impares".

EXERCÍCIO 13 — Posição das sequências

==================================================

Código:

sequences = ['ATGCCCGGCCCGGC','GCGTGCTAGCAATACGATAAACCGG','ATATATATCGAT','ATGGGCCC']


for i in range(len(sequences)):
    print(i + 1, "\t", len(sequences[i]), "\t", sequences[i])


Comando utilizado:

python3 Python04_13.1.py


Resultado:

1 14 ATGCCCGGCCCGGC
2 25 GCGTGCTAGCAATACGATAAACCGG
3 12 ATATATATCGAT
4 8 ATGGGCCC

Conclusão:

O programa utiliza "range(len(sequences))" para percorrer os índices da lista. Como os índices em Python começam em zero, foi utilizado "i + 1" para mostrar a posição das sequências começando em 1.
