EXERCÍCIO 1 — LISTAS
==================================================

>>> things = ['chocolate', 'viagem', 'música', 'praia', 'filmes']

>>> print(things)
['chocolate', 'viagem', 'música', 'praia', 'filmes']

>>> print(things[2])
música

>>> things[2] = 'livros'

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes']

>>> things.append('sorvete')

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.insert(0, 'café')

>>> print(things)
['café', 'chocolate', 'viagem', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.insert(3, 'gatos')

>>> print(things)
['café', 'chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes', 'sorvete']

>>> things.pop()
'sorvete'

>>> print(things)
['café', 'chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes']

>>> things.pop(0)
'café'

>>> print(things)
['chocolate', 'viagem', 'gatos', 'livros', 'praia', 'filmes']

>>> things.pop(2)
'gatos'

>>> print(things)
['chocolate', 'viagem', 'livros', 'praia', 'filmes']

>>> print(', '.join(things))
chocolate, viagem, livros, praia, filmes


OBSERVAÇÕES:

Em Python, os índices das listas começam pelo zero. Então, quando usamos "things[2]", estamos pegando o terceiro elemento da lista.

O "append()" serve para adicionar um elemento no final da lista, enquanto o "insert()" permite colocar um elemento em uma posição específica.

Já o "pop()" remove um elemento da lista e mostra qual foi removido. Se não colocarmos uma posição, ele remove o último elemento.

O "join()" é usado para juntar os elementos de uma lista de textos em uma única frase, usando um separador.

Com esse exercício, deu para entender que as listas são mutáveis, ou seja, podemos alterar, adicionar e remover elementos depois que a lista já foi criada.

EXERCÍCIO 2 — STRINGS, LISTAS E ORDENAÇÃO
==================================================

Código:

taxa = "sapiens, erectus, neanderthalensis"

print(taxa)
print(taxa[1])
print(type(taxa))

species = taxa.split(", ")

print(species)
print(species[1])
print(type(species))

print(sorted(species))
print(sorted(species, key=len))

Comando utilizado:

python3 Python04_2.1.py


RESULTADO:

sapiens, erectus, neanderthalensis
a
<class 'str'>
['sapiens', 'erectus', 'neanderthalensis']
erectus
<class 'list'>
['erectus', 'neanderthalensis', 'sapiens']
['sapiens', 'erectus', 'neanderthalensis']


OBSERVAÇÕES:

A variável "taxa" é uma string, como mostra o resultado "<class 'str'>". Como a indexação começa em zero, "taxa[1]" retorna o segundo caractere da string.

O "split(', ')" divide a string usando vírgula e espaço como separador, criando uma lista chamada "species".

A variável "species" é uma lista, como mostra o resultado "<class 'list'>".

A função "sorted()" organiza os elementos em ordem alfabética. Quando usamos "key=len", ela passa a organizar os elementos de acordo com o tamanho de cada um.

Também foi possível perceber que "sorted()" cria uma nova lista ordenada, sem modificar a lista original.

EXERCÍCIO 3 — Cópia de listas
================================================== 

Método 1:

my_list = ['a', 'bb', 'ccc']
list_copy = my_list
print(my_list)
list_copy.append('dddd')
print(my_list)

Resultado:

['a', 'bb', 'ccc']
['a', 'bb', 'ccc', 'dddd']

Método 2:

my_list2 = ['a', 'bb', 'ccc']
list_copy2 = my_list2.copy()
print(my_list2)
list_copy2.append('dddd')
print(my_list2)

Resultado:

['a', 'bb', 'ccc']
['a', 'bb', 'ccc']

Conclusão:
A diferença é que, no primeiro caso, "list_copy" e "my_list" apontam para a mesma lista. Então, se eu mudar "list_copy", a mudança também aparece em "my_list".

No segundo caso, ".copy()" cria uma nova lista, separada da original. Por isso, se eu alterar "list_copy2", "my_list2" continua igual.

EXERCÍCIO 6 — Números pares

==================================================

Código:

numbers = [101, 2, 15, 22, 95, 33, 2, 27, 72, 15, 52]

for n in numbers:
    if n % 2 == 0:
        print(n)


Comando utilizado:

python3 Python04_6.1.py


Resultado:

2
22
2
72
52

Conclusão:

O comando "for" percorre todos os números da lista. Para verificar quais são pares, usamos "n % 2 == 0".

O operador "%" mostra o resto da divisão. Então, quando o resto da divisão por 2 é igual a zero, significa que o número é par.

Por exemplo, se "n = 6", temos "6 % 2 = 0", então o número 6 é par. Já se "n = 5", temos "5 % 2 = 1", então o número 5 não é par.

EXERCÍCIO 7 — Soma dos números pares e ímpares

==================================================

Código:

numbers = [101, 2, 15, 22, 95, 33, 2, 27, 72, 15, 52]

numbers = sorted(numbers)

soma_pares = 0
soma_impares = 0

for n in numbers:
    print(n)

    if n % 2 == 0:
        soma_pares += n
    else:
        soma_impares += n

print("Soma dos números pares:", soma_pares)
print("Soma dos números ímpares:", soma_impares)


Comando utilizado:

python3 Python04_7.1.py

Resultado:

2
2
15
15
22
27
33
52
72
95
101
Soma dos números pares: 150
Soma dos números ímpares: 286

Conclusão:

A função "sorted()" organiza os números da lista em ordem crescente. Depois, o comando "for" passa por cada número e verifica se ele é par ou ímpar.

Os números pares são adicionados em "soma_pares", enquanto os números ímpares são adicionados em "soma_impares".

Resultado:

4
5
6

Conclusão:

O módulo "sys" foi usado para que o programa recebesse informações digitadas na linha de comando. O "sys.argv[1]" pegou o primeiro valor informado e o "sys.argv[2]" pegou o segundo. Como esses valores foram recebidos como texto, usamos "int()" para transformá-los em números inteiros e poder fazer cálculos com eles.


Parte 2 — Somente números ímpares

Código:

import sys

inicio = int(sys.argv[1])
fim = int(sys.argv[2])

for n in range(inicio, fim + 1):
    if n % 2 != 0:
        print(n)

Comando utilizado:

python3 Python04_10.2.py 3 10

Resultado:

3
5
7
9

Conclusão:

O segundo programa foi modificado para mostrar apenas os números ímpares. Para isso, foi usada a condição "n % 2 != 0". Quando o resto da divisão por 2 é diferente de zero, o número é ímpar.

Por exemplo, "5 % 2 = 1", então 5 foi identificado como ímpar.

EXERCÍCIO 13 — Posição das sequências

==================================================

Código:

sequences = ['ATGCCCGGCCCGGC','GCGTGCTAGCAATACGATAAACCGG','ATATATATCGAT','ATGGGCCC']


for i in range(len(sequences)):
    print(i + 1, "\t", len(sequences[i]), "\t", sequences[i])


Comando utilizado:

python3 Python04_13.1.py


Resultado:

1 14 ATGCCCGGCCCGGC
2 25 GCGTGCTAGCAATACGATAAACCGG
3 12 ATATATATCGAT
4 8 ATGGGCCC

Conclusão:

O programa usou "range(len(sequences))" para percorrer todas as posições da lista de sequências. O "len()" contou quantas sequências existiam e o "range()" gerou os índices para acessá-las. Como o Python começa a contar pelo índice 0, foi usado "i + 1" para mostrar a posição começando em 1. Dessa forma, o resultado ficou mais fácil de entender e identificar a sequência pela sua posição.
